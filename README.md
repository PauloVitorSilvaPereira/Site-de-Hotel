# 🎯: Objetivo


Um hotel ficticio solicitou a criação de um site para a apresentação dos recursos do hotel e uma parte para realizar as reservas. Contendo o front-end e uma integração com o back-end, através do node.js e json.

Ao cadastrar uma nova reserva, ela aparecerá junto das outras já realizadas na tabela do tabela.html
